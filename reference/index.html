Application Notes

API 6A · FLANGE TYPES AND RING COMPATIBILITY

API 6B vs. API 6BX

API 6B flanges (2,000–5,000 psi) use R-type or RX-type ring gaskets in an octagonal or oval groove. API 6BX flanges (10,000–15,000 psi) use BX-type pressure-energized rings and are not interchangeable with 6B flanges or ring types.

RX vs. R Rings

RX rings share the same ring number as R rings and are interchangeable in the same groove — RX is pressure-energized and preferred for higher pressures within 3K–5K service. R and RX rings use the same groove; BX requires a different groove profile.

Ring Gasket Materials

Ring gaskets must be softer than the flange body material. Common materials: soft iron, 316L SS, Inconel 625. Material selection is governed by process fluid, temperature, and flange material grade (AA–FF). Always confirm material compatibility per API 6A Annex D.

Stud Length Notes

Stud lengths shown are nominal for full thread engagement with heavy hex nuts (ASTM A194 Grade 2H or equivalent). Confirm thread engagement ≥ 1× stud diameter at each end. Actual required length varies with nut height and clamp requirements.
